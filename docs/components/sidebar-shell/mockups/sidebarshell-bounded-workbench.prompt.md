# Bounded Workbench Image Generation Prompt

Mode: Built-in `imagegen`.

Use case: `ui-mockup`.

Asset type: High-fidelity UX direction board for a React component-library
SidebarShell specification.

## Prompt

Create a polished 16:9 design board for a distinctive application shell
concept named “Bounded Workbench”. Show four coordinated interface postures in
one presentation: desktop expanded navigation, desktop compact icon rail, the
same shell embedded inside a bounded work area rather than occupying the whole
browser viewport, and narrow mobile with an open navigation drawer.

Use a neutral design-review canvas with four clean mockup frames and no
decorative device hardware. Show a production SaaS operations workspace shell.
The signature composition is an L-shaped “workspace spine”: a deep graphite
navigation surface rises into a compact brand cap, while a slim contextual
command deck begins over the main work stage rather than spanning blindly
across the navigation. The main stage is a warm off-white inset canvas with
restrained rounded corners, clear breadcrumbs/title/actions, dense data cards
and table content, and an obvious but elegant collapse seam control. The
contained posture must visibly demonstrate that the shell adapts to its own
container, not only the browser viewport. The mobile posture uses a proper
modal drawer and edge-to-edge command deck.

Use a high-fidelity product-design style: refined enterprise SaaS, open-code
design-system aesthetic, and practical to build with React and Tailwind CSS. No
glassmorphism or fantasy UI. Compose one landscape board with a large desktop
expanded mockup on the left, compact and contained mockups stacked on the
right, and the mobile posture as a narrow frame. Keep each posture legible and
spatially consistent.

Use crisp flat UI presentation with a calm, focused, confident mood. Use
graphite and near-black navigation, a warm neutral main canvas, a restrained
teal/cyan current-state accent, subtle amber status accents, and accessible
contrast.

Use only these short text strings where needed: “Bounded Workbench”, “Command
center”, “Overview”, “Incidents”, “Deployments”, “Search”, “Focus”, and “Main
content”. Do not add explanatory paragraphs.

Emphasize structural differentiation through the L-shaped spine, contextual
command deck, inset work stage, container-aware contained posture, and clear
landmarks. Navigation content stays semantically separate from the shell. Show
an unmistakable expanded-to-compact relationship. Keep touch targets
plausible.

Avoid copying Mantine AppShell, MUI Toolpad DashboardLayout, shadcn sidebar
demos, Carbon UI Shell, Cloudscape AppLayout, or generic admin dashboard
templates. Avoid floating glass panels, neon gradients, excessive pills,
illegible microtext, logos, and watermarks.
