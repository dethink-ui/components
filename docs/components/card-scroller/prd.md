# CardScroller PRD

GitHub issue [#415](https://github.com/parveshh/dethink-components/issues/415) is the source of truth for this PRD.

The component provides a registry-portable card choice pattern for SaaS dashboards and settings flows. It separates native user-driven scrolling from radio selection, adapts to its container instead of the viewport, supports RTL and accessibility modes, and adds no motion runtime. The accepted implementation is delivered through issues [#416](https://github.com/parveshh/dethink-components/issues/416)–[#418](https://github.com/parveshh/dethink-components/issues/418).
