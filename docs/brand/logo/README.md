# Dethink angled-notch logo

Editable vector reconstruction of the selected generated concept. These are symbol assets; they do not contain the generated wordmark.

## Files

- dethink-mark-ocean.svg — teal, cyan and cobalt; use on light backgrounds.
- dethink-mark-black.svg — single-colour dark ink.
- dethink-mark-white.svg — reversed single-colour mark for dark backgrounds.
- dethink-mark-currentcolor.svg — inherits text colour when embedded inline. An SVG loaded through an img element does not inherit the parent page colour.

All marks use the same viewBox and three filled paths. They contain no raster images, fonts, external dependencies, filters or strokes. Backgrounds are transparent. Edit fills to recolour; scale uniformly and preserve the negative-space cuts.

## Usage

Use the monochrome mark at small sizes. Suggested starting minimum: 24 px wide; check the notch at the actual displayed size before using it as a favicon. Leave clear space around the symbol of at least one stem width. Do not stretch or rotate the mark.

Ocean colours: teal #00A8B8, cyan #00A9EE, cobalt #2455F5. For dark surfaces, use the white version for maximum clarity.

## Wordmark and release preparation

The generated “dethink” lettering is a raster reference, not a supplied font. A final horizontal and stacked wordmark should use an intentionally selected, appropriately licensed typeface, with optical kerning reviewed and text converted to vector outlines. Do not automatically trace the generated lettering or assume a font match.

These SVGs are a geometric reconstruction, not pixel-exact tracing. Review the shape at production sizes before release. No application branding has been replaced.
